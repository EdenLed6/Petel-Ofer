# 🍇 הפטל של עופר – אתר המשק

אתר מלא למשק "הפטל של עופר" – משק חקלאי משפחתי בוטיקי לגידול פטל ופירות יער בנתיב העשרה שבעוטף עזה.

## מה כלול באתר

| חלק | נתיב | תיאור |
|---|---|---|
| דף נחיתה | `/` | סיפור המשק, אפשרויות קטיף, שעות, עדכונים, מוצרים מומלצים |
| חנות | `/shop` | קטלוג מוצרים, עגלת קניות, צ'ק-אאוט עם משלוח/איסוף |
| קטיף וביקור | `/visit` | מסלולי קטיף עצמי ומידע למבקרים |
| אירועים | `/events` | טופס בקשת הצעת מחיר לאירועים פרטיים ועסקיים |
| צור קשר | `/contact` | טלפון, וואטסאפ, Waze וטופס פנייה |
| דפים משפטיים | `/accessibility`, `/terms`, `/privacy`, `/shipping-returns` | הצהרת נגישות, תנאי שימוש, מדיניות פרטיות (כולל תיקון 13), ביטולים לפי חוק הגנת הצרכן |
| ניהול | `/admin` | לוח בקרה: הזמנות, מוצרים, אירועים, הודעות, עדכונים והגדרות |

בנוסף: באנר הסכמת עוגיות, ווידג'ט נגישות (גודל טקסט, ניגודיות, הדגשת קישורים, עצירת אנימציות), `sitemap.xml` ו-`robots.txt`.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:3000
```

בסיס הנתונים (SQLite) נוצר אוטומטית בתיקיית `data/` עם מוצרים והגדרות לדוגמה בהפעלה הראשונה.

## ממשק הניהול

- כתובת: `/admin`
- סיסמת ברירת מחדל: `petel2026!`

**חשוב לפני עלייה לאוויר** – הגדירו משתני סביבה:

```bash
ADMIN_PASSWORD=סיסמה-חזקה-משלכם
SESSION_SECRET=מחרוזת-אקראית-ארוכה
SITE_URL=https://your-domain.co.il
```

## תשלומים

כרגע ההזמנות נקלטות במערכת והתשלום מתואם מול הלקוח (ביט/פייבוקס/העברה/מזומן/טלפוני) – מתאים לשלב הראשון.
לסליקת אשראי אונליין מלאה יש לחבר ספק סליקה ישראלי (Grow/משולם, PayPlus, Tranzila וכו') – נקודת החיבור הטבעית היא ב-`app/actions.ts` בפונקציית `createOrder`, לאחר יצירת ההזמנה.

## טכנולוגיות

- **Next.js 16** (App Router) + React 19 + TypeScript
- **Tailwind CSS 4** – עיצוב RTL מלא בעברית, פונט Heebo
- **SQLite** (better-sqlite3) – ללא צורך בשרת DB חיצוני
- Server Actions לכל הטפסים וההזמנות

## פריסה (Deploy)

האתר דורש שרת Node (לא סטטי) בגלל בסיס הנתונים וממשק הניהול:

- **VPS / Railway / Render / Fly.io**: `npm run build && npm start`
- שימו לב: תיקיית `data/` צריכה להיות על דיסק מתמיד (persistent volume) כדי שההזמנות יישמרו.
